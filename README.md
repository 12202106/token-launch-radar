Token Launch Radar ranks the pre-token DeFi protocols in a sealed DefiLlama snapshot by what their token launch would be worth, and gives each one a concrete farm plan with costs and time. The board covers all 40 watchlist protocols plus 138 early finds below the $50M floor, scored by a model derived from the snapshot's own figures: TVL, seven-day growth, how long the protocol has run with no token, and how many chains it runs on.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
